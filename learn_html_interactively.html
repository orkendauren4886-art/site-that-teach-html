Project Pitch & Defense Specs

Overview for school/competition presentations

Goal & Target Audience

Designed as an engaging, interactive educational web platform that helps beginners master core HTML elements with instant visual feedback, eliminating the setup friction of local editors.

Technical Stack & Architecture

  • Structure & Design: HTML5, Tailwind CSS for clean layout & responsive UI.
  • Modular JS Engine: Clean separation of concerns into Editor, UI, Toast, and Particle modules.
  • Sandbox Engine: Dynamic iframe document writing for real-time code rendering.
  • Background Canvas: Lightweight HTML5 2D Canvas particle animation loop.

Key Features Highlight

1-Click template insertion into the live sandbox, responsive live iframe output, tag anatomy visualizer, and toast notifications.
